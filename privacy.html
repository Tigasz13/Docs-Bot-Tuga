🔒 Política de Privacidade

Última atualização: 2026

1. Introdução

Esta Política de Privacidade explica que dados o BOT TUGA pode tratar e como esses dados são utilizados para garantir o funcionamento do serviço.

2. Dados Recolhidos

  • ID dos servidores.
  • ID dos canais.
  • ID dos utilizadores.
  • ID dos cargos.
  • Configurações do bot.

3. Dados que NÃO Recolhemos

  • Palavras-passe.
  • Mensagens privadas.
  • Dados bancários.
  • Informações de pagamento.
  • Endereços de e-mail.

4. Finalidade da Recolha

Os dados são utilizados exclusivamente para permitir que as funcionalidades do BOT TUGA funcionem corretamente.

5. Armazenamento

Os dados são armazenados apenas durante o tempo necessário ao funcionamento do bot.

6. Partilha de Dados

O BOT TUGA não vende nem partilha dados pessoais com terceiros, salvo quando exigido por lei.

7. Segurança

São aplicadas medidas técnicas e organizativas para proteger os dados armazenados contra acessos não autorizados.

8. Direitos do Utilizador

  • Solicitar a eliminação de dados, quando aplicável.
  • Solicitar informação sobre os dados armazenados.
  • Deixar de utilizar o bot a qualquer momento.

9. Serviços de Terceiros

O BOT TUGA utiliza a API oficial do Discord e poderá utilizar outros serviços necessários ao seu funcionamento.

10. Conservação dos Dados

Os dados deixam de ser utilizados quando deixam de ser necessários para o funcionamento do serviço ou quando são removidos de acordo com a legislação aplicável.

11. Alterações

Esta Política de Privacidade pode ser atualizada periodicamente para refletir alterações ao BOT TUGA ou à legislação aplicável.

12. Aceitação

Ao utilizar o BOT TUGA, o utilizador confirma que leu e aceita esta Política de Privacidade.
